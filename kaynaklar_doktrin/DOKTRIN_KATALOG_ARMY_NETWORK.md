# Army doktrin yayin katalogu (Army_Doctrine_Network deposu)

Kaynak: https://github.com/jamestollefson/Army_Doctrine_Network (Haziran 2017 durumu; `j. doc_with_dates.csv`, 374 yayin).
DIKKAT: Depo YALNIZ atif agi analizi (CSV + grafik + python) icerir; doktrin METINLERI yoktur (README'de acikca belirtilmis). Bu dosya, hangi yayinlarin ise yarayacagini gosteren bir katalogdur.
Yayinlar Army Publishing Directorate'ten (apd.army.mil) indirilebilir; indirilince metne cevrilip `kaynaklar_doktrin/` altina eklenir.
